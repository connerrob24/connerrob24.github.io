Data

For this SQL project, we built a small MLB team-statistics database using three datasets pulled from FanGraphs: team batting, team pitching, and team fielding. Using the baseballr package in R, we created a vector of seasons and looped through each year to collect team-level statistics from 2015 through 2024, excluding the shortened 2020 season. Each dataset was cleaned by removing unnecessary columns, renaming variables, and saving the final versions as CSV files before loading them into a DuckDB database. This gave us three connected tables that could be queried with SQL to compare offensive production, pitching performance, and defensive value across MLB teams and seasons.

Primary Query

The main goal was to see whether teams with stronger defensive performance also tended to have lower ERAs. To do this, we worked with team-level pitching and fielding data, joining the tables so that each row represented one team with its ERA, OAA, and DRS values. ERA was used as the main measure of run prevention, while OAA and DRS were used to evaluate defensive quality. After combining the data, we created defensive tiers to group teams into Excellent, Mediocre, and Poor Defense, which allowed us to compare overall defensive performance against team ERA in a clearer way.

  • First joining the team_pitching and team_fielding data frames
  • Keeping only rows in 2024 season and removing NA’s
WITH joined_data AS (
    SELECT
        p.Season,       
        p.team_name,    
        p.ERA,          
        f.OAA,          -- Outs Above Average
        f.DRS           -- Defensive Runs Saved
    FROM team_pitching AS p
    JOIN team_fielding AS f
        ON p.Season = f.Season
       AND p.team_name = f.team_name
    WHERE p.Season = 2024
    AND f.OAA IS NOT NULL),

  • Now I am classifying each team into a defensive tier using OAA and DRS.

    • OAA - A statcast defensive metric measuring how many outs a fielder saves, incorporating range and play difficulty
    • DRS - A statistic that measures how many runs a player saves or costs their team compared to an average fielder

  • The CASE statement works like an if/else structure: teams with strong values in both metrics are labeled Excellent Defense, teams with weak values in both are labeled Poor Defense, and all others are labeled Mediocre Defense.

  • The new defense_tier variable is then used to color the ERA plot and compare defensive performance with run prevention.

SELECT
        Season,
        team_name,
        ERA,
        OAA,
        DRS,
        CASE
        
            WHEN
                (CASE WHEN OAA >= 25 THEN 1 ELSE 0 END) +
                (CASE WHEN DRS >= 5 THEN 1 ELSE 0 END) = 2
            THEN 'Excellent Defense'

            WHEN
                (CASE WHEN OAA <= 0 THEN 1 ELSE 0 END) +
                (CASE WHEN DRS <= 0 THEN 1 ELSE 0 END) = 2
            THEN 'Poor Defense'

            ELSE 'Mediocre Defense'

        END AS defense_tier

    FROM joined_data)

Visualization

The plot below orders teams by ERA, with better run prevention on the left and worse run prevention on the right. Each team is colored by a defensive tier created from its 2024 OAA and DRS values. Overall, the visualization suggests that defense may relate to ERA, since poor defensive teams generally appear more often in the mid-to-high ERA range. However, the colors are still mixed across the plot, and even strong or mediocre defensive teams cover a wide range of ERAs. This shows that defense matters, but ERA is also shaped by other factors like pitching talent, strikeouts, walks, and home runs allowed.
